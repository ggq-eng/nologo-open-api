# nologo-open-api

> 来源分类：**待确认** ｜ 导出批次：review

抖音、小红书、豆包、千问等平台的图片/视频去水印解析。当用户需要去除视频/图片水印、获取无水印直链、调用解析API、查询价格时使用此skill。

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/nologo-open-api        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/nologo-open-api   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
